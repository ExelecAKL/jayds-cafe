# Admin and Help reference decisions — 16 October 2026

References: the operator's actual stock-movement screenshot, the existing Jayds tables/drawers/finance chart, the approved ZUS observation catalogue, and the previously read bundled craft/motion guidance. No Refero MCP or disconnected phone is used.

- Keep the warm Jayds palette and existing accessible drawer/dialog system. A visible View details button makes every movement, waste, physical count and planning entry keyboard accessible; clicking a row does the same. Details identify the source order, batch, receipt/count and actor where known. Missing legacy references stay explicitly unknown.
- Stock planning opens with available stock, projected coverage, purchase suggestion and reason. Ingredient detail shows historical daily usage and a separate projected depletion curve, units, matching table, method and freshness/history notices. Charts supplement actionable numbers; no unsupported accuracy claim or decorative diagram.
- Refresh only refreshes forecasts. Creating purchase drafts requires reviewing the server's current 14-day suggestions. Changed suggestions invalidate the review; edited drafts and approved purchases remain protected.
- Export becomes a dedicated Reports navigation item. Group application tables by Food & stock, Orders & sales, Purchasing, People & support and Settings/other; allow group or individual selection and preview counts. Downloads contain a manifest. Passwords, access tokens, push credentials and private file contents are excluded explicitly. A frozen server snapshot prevents records being silently lost when live data changes during download.
- Customer Help uses short topic choices, useful answers and direct order/recovery links, followed by an optional private-request form and request history. Preserve labels and required/optional markers; show loading, empty, failure and retry states. Keep private case state scoped to the authenticated owner and support guest order grants.


The operator clarified that simplification means how Admin looks and feels, not more explanatory copy. Key figures and primary actions come first; references, history and chart detail sit behind a deliberate open action. Orders, categories and the recipe editor keep their existing structure. Product photos use a file chooser. Existing Sales Reports are retained while export moves to its own section. Overview shortcuts are compact; purchasing stages change the actual list filter. Opening hours use aligned day rows, and branch/location fields move into a disclosure that opens on validation errors. Motion uses explicit properties and respects reduced motion; it never delays a data update or removes the keyboard path.

### 2. QR System — Three Flows

#### A. Void Authorization (Admin → POS)
- **Admin page:** `apps/admin/app/(admin)/void-tokens/page.tsx`
  - Generates UUID token → SHA-256 hashes it → stores hash in `void_tokens` table (5-min expiry)
  - Shows raw token as QR code with live countdown timer
  - History table of recent tokens with status
- **POS page:** `apps/pos/app/(pos)/void/page.tsx`
  - Two-step flow: select order → scan manager QR
  - Scans QR → hashes scanned value → calls `void_order_with_token()` RPC
  - RPC atomically validates token, marks it used, cancels order

#### B. Pickup Confirmation (Customer → POS)
- **Customer side:** `apps/customer/app/(shop)/orders/[id]/page.tsx`
  - Pickup QR auto-generated by DB trigger (`trg_generate_pickup_token`) on order insert
  - QR shown on order tracking page when status is not completed/cancelled
  - QR encodes: `pickup:{orderId}:{tokenHash}`
- **POS side:** `apps/pos/app/(pos)/dashboard/page.tsx`
  - "📷 Scan Pickup" button opens camera scanner
  - Validates token → checks payment status:
    - **If unpaid:** shows toast "Order unpaid" → redirects to `/payment/{orderId}` after 1.5s
    - **If paid:** marks token used → sets order `completed` → shows success toast
  - **"Move to Completed" button REMOVED** from Ready column — only QR scan can complete

- **POS payment page:** `apps/pos/app/(pos)/payment/[id]/page.tsx` — **REWRITTEN**

  - Shows QR encoding URL: `{customerAppUrl}/receipt/{token}`
  - "Generate Receipt QR" button if not auto-generated
  - Also added: Exact Amount shortcut, "New Order" quick-restart button

## Important Architecture Notes

1. **POS cart is LOCAL** — uses `useReducer` in the page, NOT the shared `CartContext` (which is for customer app)
2. **Void tokens use SHA-256** — raw UUID shown as QR, DB stores hash only. POS hashes scanned value before lookup.
3. **Pickup tokens auto-generated** — DB trigger creates them on order insert when `customer_id IS NOT NULL`
4. **Order completion is QR-only** — `NEXT_STATUS` mapping removed `ready → completed`. Only QR scan can mark complete.
5. **Geofencing** — Customer ordering restricted to Dasmariñas, Imus, Bacoor (Cavite) via `useGeofence` hook
6. **Shift tracking** — Auto clock-in/out in admin and POS layouts
7. **Profile guard trigger** — `protect_profile_mutation` on profiles table blocks role/points/email changes. Must disable temporarily for emergency fixes.
